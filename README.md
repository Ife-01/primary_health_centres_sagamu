Primary Health Centres — Sagamu

This project is a static website that provides information about primary health centres in Sagamu, Nigeria. It serves as a directory and resource hub to improve community access to health information.

🌍 Project Overview

The site is designed to:

Showcase a directory of primary health centres.

Provide easy navigation with maps, data, and relevant contact details.

Support search engine visibility through robots.txt, sitemap.xml, and sitemap.txt.

Enable users to find verified information about health facilities.

primary_health_centres_sagamu
