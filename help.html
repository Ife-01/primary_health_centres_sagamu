Finding a health centre

Everything happens on the directory page. The map and the list always show the same facilities, so whatever you search or filter changes both.

Search

Type a name, address, ward or part of the directions, for example Ogijo or Sabo. Small spelling mistakes are forgiven. You can also search by postcode, which is explained below.

Ward filter

Pick a ward to see only the health centres in it. Choose All wards to go back to everything.

Day and clinic filters

  • Day: shows the health centres that are open on that day. Every health centre is listed as open 24 hours, every day, so by itself this shows them all. That is a general assumption, so call or ask ahead.
  • Clinic: choose Immunization or Antenatal to see only health centres whose ward runs that clinic. Clinic days are set for each ward, so every health centre in a ward has the same days.
  • Both together: the day then means the clinic day. For example, Antenatal and Mon shows health centres with an antenatal clinic on Monday.

Clinics currently run from Monday to Thursday. If you pick a clinic and a day with no clinics, such as Friday, the list will be empty. The health centres are still open. Choose Any clinic to see them again.

Reading a result

Each health centre appears as a card in the list and as a pin on the map. Tap a pin to see the same details in a pop-up.

  • Ward and address: where the health centre is.
  • Postcode: the digital postcode, when it has been checked.
  • Directions: how to get there from a well-known place, usually by bike, tricycle (keke) or on foot. These are written for people who know the area, so look for the landmark named in them.
  • Services: Immunization, Antenatal, Delivery and Family Planning. The same four are shown for every health centre, so call or ask ahead if you need a specific service.
  • Clinic days: badges such as Immunization: Wed and Antenatal: Mon show the days those clinics run. They are set for the whole ward, so health centres in the same ward share the same days.
  • Opening hours: the days and hours the health centre is open.
  • Open in Maps: opens Google Maps at the health centre's pin so you can get turn-by-turn directions.

Always confirm details with the health centre before you travel.

Postcodes

What is a postcode?

The Nigerian digital postcode is a short code that points to a specific place, such as a building, a street or a district. It is issued by NIPOST, the Nigerian Postal Service. Each code has 11 letters and numbers, and the first two letters tell you the state. Codes for Ogun State start with OG.

How to read one

Take OG-20-B70-JY-20. It reads from the widest place to the narrowest:

PartLevelWhat it points to
OGStateOgun State
20Local governmentSagamu
B70DistrictA district within Sagamu
JYAreaAn area within that district
20BuildingOne building or location

The hyphens are only there to make the code easier to read. OG20B70JY20 is the same code. The level names follow NIPOST's own description. The exact position of each part is based on how the codes in this directory are laid out.

Searching by postcode

Type all or part of a postcode in the search box. The more of the code you type, the narrower the results.

Type thisTo findTry it
OGEverything in the stateOG
OG-20Everything in SagamuOG-20
OG-20-B70One districtOG-20-B70
OG-20-B70-JYOne areaOG-20-B70-JY
OG-20-B70-JY-20One buildingOG-20-B70-JY-20
  • Hyphens, spaces and capital letters don't matter. og20b70 works the same as OG-20-B70.
  • You can start at the district. B70 and B70-JY work without typing OG-20 first.
  • An area code can't be searched on its own. Typing just JY won't work, so put the district in front, as in B70-JY.

Why does my health centre have no postcode?

We only show postcodes that have been checked. Some are still being verified and will be added when they are.

Is this the same as the old 6-digit postal code?

No. The digital postcode is longer and points to a much more specific place than the old code did.

How do I find a postcode of my own?

Use the NIPOST postcode finder, or read more at postcode.gov.ng.

Report a problem

This directory was put together by the National Health Fellows and was last checked on 14 August 2025, so some details may have changed. If you spot something wrong, such as a pin in the wrong place, directions that no longer work, a wrong clinic day or a missing postcode, please let the National Health Fellows team know.

When you report it, include the health centre's name and what needs to change.
